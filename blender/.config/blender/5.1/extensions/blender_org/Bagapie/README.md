BagaPie Modifier and Assets Installation :

Which version should I install ?

	Blender 4.2:
		- BagaPie V10.x.x

	Blender 3.4:
		- BagaPie V0.9.x.x
		- BagaPie Assets is part of BagaPie Modifier, you just have to install paks (BagaPie_Assets_Vol_X.baga)
		  Installation : BagaPie Modifier > Assets > Install package (install every packs one by one)

	Blender 3.3:
		- BagaPie Modifier V0.8.x.x
		- BagaPie Assets V3.x.x
	
	Blender 3.2:

	Blender 3.1:

		- BagaPie Assets V2.x.x

	Blender 3.0:

		- BagaPie Assets V1.x.x

	Blender 2.93:

INSTALLATION :
	Do the same operation for BagaPie Modifier and Assets.

	If you get it trough the Blender Extension platform (https://extensions.blender.org/):
 		- Drag and drop it to Blender (opened),
   		- Update it in the Preferences > Extension > Update

	If this is your first installation of BagaPie:
		- Open preferences : Edit > Preferences > Addon
		- Install > Go get the ZIP file (DON'T UNZIP IT) > Install,
		- Wait a few seconds and activate the addon (checkbox),
		- If you wish, install the library presets in the addon preferences,
		- Save Preferences,
		- Enjoy ! 
	
	If you already have BagaPie:
		- Open preferences : Edit > Preferences > Addon
		- Search BagaPie
		- Uninstall it,
		- Restart Blender,
		- Install the new version of BagaPie,
		- If you wish, install the library presets in the addon preferences,
		- Save Preferences,
		- Enjoy !
